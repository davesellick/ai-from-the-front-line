# AI from the Front Line: AI in accounting

The evolving deck for sessions with firms' teams. Working title, Dave's words.

Live at `/ai-in-accounting`, which redirects to this folder. 93 slides: 59 for the session, then a Backup divider and 33 backup slides.

Built on 23 November 2026 from Auto Bank Wreck (the base, its look and its notes) and AI Native is a Lie, in the running order of the first firm session plan. Edit `index.html` directly from here on. Images this deck uses were copied into `images/` (AI Native ones under `images/from-ai-native/`), so the two source decks can change without breaking this one.
